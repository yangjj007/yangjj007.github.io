# Review-only scope and reuse notice

This ZIP is an anonymous review-only data sample for manuscript TMI-2026-1070. It is supplied solely to let editors and reviewers inspect benchmark records, image pairs, instructions, answers, prompt material, and curation criteria during peer review.

The package is not a public dataset release, clinical decision-support material, or a claim that any synthetic image should be used for diagnosis. It contains no source-code or executable files. No patient identity, author identity, API credential, repository account identifier, or absolute local path is included. Source-dataset labels are retained for audit only. Any later reuse or public release must follow the original source-data licenses, institutional approvals, and data-governance requirements.
